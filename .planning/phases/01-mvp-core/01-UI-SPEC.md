## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding between icon and label |
| sm | 8px | Compact element spacing, input internal padding |
| md | 16px | Default element spacing, card padding, form field gaps |
| lg | 24px | Section padding, card body padding |
| xl | 32px | Layout gaps between major sections |
| 2xl | 48px | Page section breaks (e.g., between KPI grid and transactions list) |

Exceptions:
- Touch targets minimum 44px height on mobile (buttons, nav items, agenda slots)

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 (regular) | 1.5 | Paragraphs, descriptions, table cells, transaction rows |
| Label | 14px | 500 (medium) | 1.4 | Form labels, nav items, stat labels, table headers |
| Heading | 20px | 600 (semibold) | 1.2 | Page titles, section headers, card titles |
| Display | 28px | 700 (bold) | 1.1 | KPI numbers (CA jour, CA mois), hero headline on homepage |

Font stack: `'Inter', system-ui, -apple-system, sans-serif`

Additional rules:
- FCFA amounts always use `font-variant-numeric: tabular-nums` for alignment
- All text in French — no English fallback labels
- Truncation: single-line with `text-overflow: ellipsis` on service names, client names in agenda

## Interaction Patterns

### Booking Flow (3 steps)

1. **Step 1 — Services:** Grid/list of services. Each card shows name, duration, price FCFA, optional description. Client taps to add (multi-select). "Continuer" button at bottom (fixed on mobile). Step indicator: "1/3".
2. **Step 2 — Collaborateur:** List of available collaborators with avatar + name. "Premier disponible" option at top. Skip entirely if salon has 1 collaborator. "Continuer" button. Step indicator: "2/3".
3. **Step 3 — Informations + OTP:** Phone input (+241), name input, email input (optional). On submit: OTP sent. Inline OTP input (6 digits). On verify: booking confirmed or payment flow starts. Step indicator: "3/3".

### Onboarding Wizard (4 steps)

Linear with progress bar at top (25% increments).

1. **Profil salon:** Nom, adresse, telephone, photo (optional upload). "Continuer".
2. **Services:** Add services (nom, duree, prix FCFA, description optionnelle, paiement config). Minimum 1 required. "Continuer".
3. **Horaires:** Weekly schedule per day (ouverture/fermeture + pause optionnelle). Default 9h-18h. "Continuer".
4. **Equipe (optionnel):** Add collaborators (nom, telephone). Can skip. "Terminer".

### Agenda Interactions

- **Click empty slot:** Opens Dialog with walk-in quick form (30s target).
- **Click existing appointment:** Opens Dialog with details + actions (Encaisser, Modifier, Annuler).
- **Swipe left (mobile):** No swipe gestures in Phase 1 — tap only.
- **Date navigation:** Left/right arrows + date picker calendar.
- **View toggle:** Tabs component (Jour / Semaine). Week view desktop only (>= 1280px).

### Encaissement Flow

1. Pro taps "Encaisser" on appointment.
2. Dialog shows: service(s), total amount FCFA.
3. RadioGroup: Cash / Airtel Money.
4. If Cash: single "Confirmer" button. Done.
5. If Airtel Money: enters client phone, initiates pawaPay deposit. Shows pending spinner. Auto-updates on webhook.

### Toast Feedback

All mutations show a toast:
- Success: black background, white text, 3 seconds auto-dismiss.
- Error: red background, white text, 5 seconds, manual dismiss.

## Currency Formatting

- Display format: `9 900 FCFA` (space as thousands separator, "FCFA" suffix)
- No decimals ever (INTEGER storage)
- Right-aligned in tables
- Use `font-variant-numeric: tabular-nums` for column alignment
- Helper: `formatFCFA(amount: number): string` => `amount.toLocaleString('fr-FR') + ' FCFA'`

## Accessibility

- All interactive elements: minimum 44x44px touch target on mobile
- Focus rings: 2px offset, `#1A1A1A` color (default shadcn focus-visible)
- Color contrast: all text passes WCAG AA (verified: #333333 on #FFFFFF = 12.6:1, #666666 on #FFFFFF = 5.7:1)
- Form errors: inline below field, red text, associated via `aria-describedby`
- Dialogs: focus trap, ESC to close, aria-labelledby on title
- Loading states: Skeleton components with `aria-busy="true"`
- Language: `<html lang="fr">`
